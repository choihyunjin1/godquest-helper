## 이번 변경 사항

- 사용자가 입력한 영지 목록 순번·좌표를 그대로 사용합니다. 위치 0도 허용합니다. 영지 이름과 좌표를 OCR로 읽거나 자동 수정하지 않습니다.
- 영주 아래 보이는 첫 **선택** 버튼으로 대기 영웅을 배정합니다. 목록 전체를 먼저 훑거나 레벨로 영웅을 제외하지 않습니다. 게임에서 준비한 병력을 유지합니다.
- 출정 확인 구간의 불필요한 고정 대기를 줄이고, 같은 화면의 팝업 판정을 재사용합니다. 흐려지는 이동 아이콘의 인식을 보완했습니다.
- 첫 설치 후보 실증에서 출정 후 흰 전환 효과에 가려진 이동 표시를 확정하지 못한 사례가 발견되어, 해당 전환 효과를 보완한 뒤 다시 빌드했습니다.
- 선택한 영웅과 이동 표시의 연결, 서로 다른 두 캡처의 시각적 증거, 최대 10초 확인 기한을 유지합니다. 지도 복귀·숫자 변화·시간 기록만으로 성공 처리하지 않습니다.
- 이미 확인한 거리 안내가 닫히는 동안 같은 버튼을 반복 클릭하지 않습니다. 명시적인 게임 요청 거절·로그인 필요·알 수 없는 팝업은 보류합니다.
- 출정 단계별 시간을 로컬 진단에 남기고, 빠르게 캡처한 뒤 마지막 실패 화면이 진단 ZIP에서 빠지지 않도록 수정했습니다.
- 기존 미확정 기록과 예약을 보존하며 자동 재전송하지 않습니다. 사용자 설정·로그·예약·개인 키·OCR 라이브러리와 모델은 배포 파일에 포함하지 않습니다.

설치판에는 실행용 Python과 ADB가 포함되어 있습니다. 사용자의 별도 Python 설치·AI 앱·API 키는 필요하지 않습니다. BlueStacks와 게임 서버 인터넷 연결은 필요합니다.

첫 설치 후보에서는 확인 출정 5건과 미확정 1건이 관측되어 위 전환 효과 보완을 진행했습니다. **이는 이전 후보의 결과이며 최종 빌드의 실측 수치가 아닙니다.** 과거 미확정은 성공으로 바꾸거나 삭제하지 않고 증거와 함께 보존합니다. 앞선 소스 앱·이전 후보의 검사와 출정을 최종 설치판의 결과에 합산하지 않습니다.

신규 미확정 0건은 위 최종 설치판의 3건 실측에 대한 결과입니다. 출정 확인은 균열 파괴 성공이나 장기 무중단 운용 보장이 아니며, 다른 PC·계정과 24시간 운용 검증은 남아 있습니다.

## Windows 경고와 제한

미서명 파일이므로 Windows에서 게시자를 확인할 수 없다는 경고가 나올 수 있고, PC 보안 정책에 따라 실행이 차단될 수도 있습니다. 이번 PC의 실행·설치 성공이 다른 PC에서의 실행을 보장하지 않습니다. 보호 기능을 끄거나 정책 차단을 우회하는 방법은 제공하지 않습니다.

이전 빌드가 Windows 앱 제어 정책에 차단된 기록은 그대로 남아 있습니다. 이번 빌드의 검사·설치·운용 결과와 별도로 구분합니다. 유료 서명 인증서를 구매하거나 적용하지 않았습니다.

앱·PC·BlueStacks가 켜져 있어야 운용됩니다. 게임 오류나 로그인·알 수 없는 팝업은 사용자 조치가 필요할 수 있습니다. 사용 방법은 [사진 안내서](image-app-guide.md)를 확인하세요. 기본 설치·설정은 실제 화면 사진 13장으로 안내하며, 설명용 모의 오류 화면은 별도로 구분했습니다. 영지 사진의 순번·좌표는 입력 예시이므로 본인 값으로 바꿔야 합니다.
