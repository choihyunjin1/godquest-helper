# 배포 준비 미리보기 · 2026-10-24

대상은 Windows x64 + BlueStacks입니다. 소스의 버전 표시는 `0.5.3-image-preview`이며, 같은 버전 문자열의 이전 설치 파일에 최신 수정이 들어 있다는 뜻은 아닙니다.

**최신 설치 파일의 배포 검증은 보류 중입니다.** 이 문서는 검증된 설치판의 릴리스 공지가 아닙니다. 일반 사용자용 다운로드 링크는 아직 정하지 않았습니다.

## 최신 변경 사항

- 출정 확인 구간의 불필요한 고정 대기를 제거하고, 동일 화면의 팝업 판정을 재사용합니다.
- 회색·반투명으로 흐려지는 이동 아이콘 세 형태를 추가했습니다. 선택 영웅과 이동 표시의 연결, 서로 다른 두 화면의 증거, 최대 10초 확인 기한은 유지합니다.
- 한 번 확인한 거리 안내가 닫히는 동안 같은 버튼을 다시 누르지 않습니다. 명시적인 게임 요청 거절과 로그인 필요는 보류합니다.
- 출정 단계별 시간을 로컬 진단에 남기고, 빠른 캡처 뒤 마지막 실패 화면이 진단 ZIP에서 누락되지 않도록 수정했습니다. 시간 기록만으로 출정 성공을 판단하지 않습니다.

기존 수동 영지 순번·좌표 등록, 위치 0 허용, OCR 없는 이미지 판단, 영주 아래 첫 대기 영웅 선택, 게임에서 준비한 병력 유지 방식은 그대로입니다. 기존 미확정 기록을 성공으로 바꾸거나 자동 재전송하지 않습니다.

## 확인한 범위

| 항목 | 결과 |
| --- | --- |
| 최신 이미지 엔진·앱 회귀 검사 | **1,254개 통과** |
| 현재 PC의 최신 소스 앱 실제 운용 | **약 10분**, 신규 확인 출정 **3건**, 신규 미확정 **0건** |
| 기존 미확정 기록 | **13건과 원본 증거 보존**, 성공으로 변경하지 않음 |
| 해당 짧은 관측의 탐색 실패 | 출정 전 1회, 해당 대상만 후순위로 넘긴 뒤 다른 대상으로 정상 출정 |
| 최신 설치 파일의 설치·연결·등록·출정 | **미완료** |
| 다른 PC·계정 및 24시간 운용 | **미검증** |

세 신규 출정은 선택한 영웅의 이동 표시와 연결된 출정 애니메이션을 서로 다른 두 캡처에서 확인했습니다. 게임 지도 복귀나 숫자 변화만으로 계산하지 않았습니다. 이는 출정 확인이며 균열 파괴 결과나 무중단 운용 보장은 아닙니다. 짧은 관측의 신규 미확정 0건이 모든 인식 사례의 해결을 뜻하지는 않습니다.

## 설치판이 아직 없는 이유

최신 수정 전 실행 파일 후보는 Windows 앱 제어 정책에 차단됐습니다(**WinError 4551**). 해당 후보는 자체 점검을 통과하지 못해 성공 manifest·ZIP·Setup을 만들지 않았습니다. 최신 출정 수정까지 반영한 새 설치판의 실증도 아직 진행하지 못했습니다. 현재 사용할 코드 서명 인증서는 없습니다.

이전 버전의 EXE·설치 파일이나 이전 성공 기록을 최신 수정본의 검증 결과로 사용하지 않습니다. 서명 준비용 소스 ZIP이 제공되더라도 설치 앱은 아닙니다. 보안 정책을 끄거나 실행 차단을 우회하는 방법은 제공하지 않습니다.

## 설치판 공개 전 남은 확인

1. 최신 소스와 문서를 동결하고, 개인 설정·기기 정보·로그·예약과 OCR 의존성이 없는 빌드를 만듭니다.
2. 정식 서명 등 실행에 필요한 조건을 마련한 뒤, 해당 EXE의 자체 점검과 새 프로필 실행을 확인합니다. 서명만으로 모든 PC의 실행을 보장하지 않습니다.
3. 현재 PC에서 실제 설치·자동 연결·수동 영지 등록·출정·중지와 바탕화면 바로가기를 확인하고 같은 빌드의 결과로 기록합니다.
4. 검증한 설치 파일의 빌드 식별·SHA-256·검증 범위와 실제 안내 사진을 GitHub Release에 함께 제공합니다.

다른 PC·계정과 장시간 운용 결과는 별도로 표시합니다. 설명용으로 만든 사진을 실제 설치 성공이나 오류 복구의 증거로 사용하지 않습니다.
