# 갓퀘스트 균열 도우미

Windows x64와 BlueStacks에서 가까운 활성 균열을 찾아 대기 영웅을 보내는 앱입니다. 사용자가 입력한 **영지 목록 순번과 출발 좌표를 그대로 사용**합니다. OCR·AI 서비스·API 키를 사용하지 않습니다.

> **현재 상태: 설치 배포 검증 보류**
>
> 최신 소스의 실제 출정은 현재 PC에서 확인했습니다. 최신 실행 파일은 Windows 앱 제어 정책에 차단되어, 일반 사용자에게 제공할 설치 파일의 검증은 끝나지 않았습니다. 이 자료는 배포 준비용 미리보기 안내입니다. 설치 앱 다운로드 링크는 아직 없습니다. [검증 범위와 변경 사항](RELEASE-NOTES.ko.md)을 확인하세요.

## 사용 환경

- Windows x64 PC와 BlueStacks
- BlueStacks에서 실행 중인 갓퀘스트와 게임 로그인
- BlueStacks의 Android 디버그 브리지(ADB) 사용 설정
- 게임 서버 인터넷 연결

검증 후 제공할 설치판에는 Python 런타임과 ADB를 포함합니다. 배포받은 사용자는 **Python·AI 앱·API 키를 따로 준비하지 않습니다.** 앱의 이미지 판단은 PC 안에서 처리하지만 게임 자체는 인터넷 연결이 필요합니다. APK와 휴대전화용 앱은 현재 제공하지 않습니다.

## 설치판이 제공되면 이렇게 시작합니다

1. GitHub의 **Releases**에서 해당 버전의 설치 파일과 검증 상태를 확인합니다. 저장소의 **Code → Download ZIP**은 설치 앱이 아닙니다.
2. 설치 후 바탕화면의 **갓퀘스트 균열 도우미**를 엽니다.
3. BlueStacks에서 게임에 로그인하고 가로 16:9 화면으로 준비합니다. ADB를 켭니다.
4. 앱의 **연결 · 영지 등록 → 자동 연결**을 누릅니다. 기기가 여러 개면 사용할 게임 기기를 선택합니다.
5. 게임 영지 목록을 맨 위부터 세어 **게임 목록 순번**과 **좌표 · 세계,왕국,위치**를 입력합니다. 사용할 영지만 **사용**으로 저장합니다. 별칭은 선택 사항입니다.
6. 게임에서 영웅과 병력을 준비하고 **운용 → 자동 운용 시작**을 누릅니다.

게임 목록의 세 번째 영지는 앱에도 `3`번으로 등록합니다. 세계·왕국은 1 이상, 위치는 **0 이상**입니다. 올림포스 신전의 위치 0도 허용합니다. 앱이 게임 글자를 읽어 등록값을 확인하거나 자동 수정하지 않으므로, 목록 순서나 좌표가 바뀌면 중지 후 직접 수정하세요.

병력 고급 설정을 비워 두면 게임에서 준비한 병력을 유지합니다. 이동시간과 레벨 입력은 필요하지 않으며, 레벨로 영웅을 제외하지 않습니다. 영주 아래 보이는 첫 **선택** 버튼으로 대기 영웅을 바로 배정합니다.

## 운용과 중지

가까운 후보부터 확인하고 실제 활성 균열 그림이 보일 때 출정합니다. 파괴된 균열은 다음 후보로 넘어가며 재생성 전에는 보내지 않습니다. 대기 영웅이 없으면 10초 간격으로 확인합니다. 여러 영지를 사용하면 순환합니다.

멈추려면 **중지 (F8)**를 누릅니다. F8은 앱이나 보조 창에 초점이 있을 때 동작합니다. 이미 출발한 군대의 게임 내 이동은 계속됩니다. 운용 중에는 앱·PC·BlueStacks와 게임 연결을 유지해야 합니다.

**확인된 출정 횟수는 균열 파괴 성공 횟수가 아닙니다.** 출정 결과가 불명확하면 화면과 예약을 보존하고 해당 대상만 제외합니다. 재시작이나 시간 경과만으로 같은 시도를 다시 보내지 않습니다.

## 오류가 보이면

- **출정 보류:** **원인 확인 · 보류 해제**에서 원인 화면과 다음 조치를 확인합니다. 로그인·알 수 없는 팝업은 게임에서 직접 처리합니다. 게임 요청 거절은 원인을 해결하고 수동 출정 성공을 확인한 뒤 해제합니다.
- **연결 실패:** 게임 로그인과 BlueStacks의 ADB 설정을 확인한 뒤 **자동 연결**을 사용합니다. 직접 지정은 고급 설정에 있습니다.
- **원인 확인이 어려움:** **로그 확인 → 최근 실패 화면 보기**와 **진단 ZIP 저장**을 사용합니다. 최신 화면이 없으면 그 사유를 표시합니다.

진단 ZIP에는 게임 화면과 좌표가 포함될 수 있으므로 공유 전에 확인하세요. 앱은 자료를 자동 전송하지 않습니다. Windows가 실행을 차단하면 보호 기능을 끄거나 차단을 우회하지 마세요.

## 개인 설정과 업데이트

배포본에는 개발자의 영지·기기·계정 설정·로그·예약을 포함하지 않습니다. 처음에는 본인의 기기에 연결하고 영지를 등록합니다. 다른 사람의 프로필을 복사해서 사용하지 마세요.

업데이트는 개인 설정과 출정 기록을 유지하도록 설계했습니다. 기존 설정에 게임 목록 순번이 없으면 직접 입력해야 합니다. 미확정 예약은 업데이트나 보류 해제로 초기화하지 않습니다. 기존 사용자의 설정 폴더를 삭제해 문제를 해결하지 마세요.

[사진 안내서](docs/image-app-guide.md)의 화면은 **설명용 모의 예시**이며 최신 설치판의 실제 연결·출정·복구 검증 증거가 아닙니다. 사진과 현재 앱의 문구·배치는 일부 다를 수 있습니다.
